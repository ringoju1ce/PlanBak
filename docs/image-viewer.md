# 图片查看器

图片预加载时，主窗口状态栏会显示正在预加载的文件；有其他后台任务时优先显示其他任务。预加载不显示进度条。

图片查看器从当前文件夹的图片候选建立浏览序列；窗口独立保存浏览位置和缩放状态，会话内的窗口共享缓存。已损坏或不可读取的图片显示错误后仍可切换到其他图片。

## 操作

- 左右方向键、上一张/下一张按钮和鼠标滚轮切换图片；循环开关只在当前窗口有效。
- Ctrl+滚轮和捏合缩放；左键拖动或触摸板双指滑动可平移放大的图片。双指滑动不会切图。
- 适应窗口与实际大小是独立操作；重新加载读取当前会话版本。
- 打开图片后后台预加载前后图片，翻页后沿当前方向预加载接下来的图片。预加载失败不弹出错误；需要实际加载时主窗口状态栏显示文件名。

预加载和当前图片加载的取消是协作式的。某些解码步骤或共享资源仍可能短暂延迟当前图片，不能保证立即中断。预加载不会绕过图片序列的首尾，即使开启循环切图也是如此。

## 缓存与大图

会话共享的解码预览缓存上限为 128 MiB、16 项；提取文件和大图分块合计上限为 512 MiB、128 项。单个提取图片文件的预览上限为 128 MiB。缓存按使用情况淘汰，正在使用的文件受租约保护；这些预算不是整个进程的内存上限。

大图使用预览和按需可见区域读取；不同格式的底层解码器和内存开销不同。HEIC/HEIF 支持取决于实际打包的解码组件。动画及多页格式当前只显示静态画面，不提供实况照片播放。
