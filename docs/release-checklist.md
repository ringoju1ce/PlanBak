# 发布前人工检查

- 在目标平台启动安装包，验证首次启动、退出与再次启动；检查中英文界面、深浅主题和高 DPI。
- 使用合成的明文与加密备份，检查打开、浏览、导出、创建副本、修改和重新打开；确认保留原始备份，取消或失败后临时文件按预期清理。
- 检查 plist、SQLite、十六进制和图片查看器；用 HEIC 和大图检查图片解码、缩放、平移及切图。
- 在真实桌面环境中检查窗口焦点、键盘快捷键、触摸板手势和拖入/拖出；确认接收程序可以读取拖出的文件。
- 对实际打入的 Python、Qt、libvips 及其他原生组件逐项核对许可证、声明和源码提供义务；按平台检查打包结果。
- 检查待发布文件不含密码、密钥、真实设备标识、私有备份、日志或本机路径。核对版本号、发布说明和下载文件的校验值。
- 如进行设备恢复验证，只在已授权的测试设备及备份副本上操作；公开结果仅保留经过脱敏的结论。
