# PlanBak

PlanBak 是一款离线桌面工具，用于浏览、导出和修改本地 iOS 备份。你可以查看备份中的文件，将所需内容导出到电脑，或在副本中添加、编辑和删除文件。

## 主要功能

- 读取未加密备份和密码已知的加密备份，按文件夹浏览内容。
- 导出文件和文件夹；内置图片、SQLite、十六进制查看器和 plist 编辑器。
- 添加、重命名、移动和删除文件，编辑 plist，并将更改写入备份副本。
- 同时打开多份备份，在窗口之间复制项目。

## 从源码运行

目前尚未提供独立安装包，以下步骤适用于 Linux。需要 Python 3.12 或更高版本。当前主要在 Linux/Wayland 环境验证，Windows 和 macOS 尚未完成实机验证。

在项目目录中创建虚拟环境并安装：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
```

启动程序：

```bash
./run.sh
```

也可以通过安装后的命令启动，或指定一份备份的文件夹（也支持包含多份备份的父文件夹）：

```bash
.venv/bin/planbak /path/to/backup
```

### 打开、导出和修改备份

1. 在程序中打开备份文件夹；加密备份需要输入备份密码。首次打开大型备份时，建立索引可能需要几分钟。
2. 浏览文件，选择需要的项目并导出，或打开支持的文件进行查看。
3. 如需修改，可添加、编辑或删除项目，然后选择“应用更改”。首次应用时，选择一个**尚不存在的新文件夹**创建备份副本；原始备份保持不变。也可通过“文件 → 创建备份副本…”提前创建副本。
4. 创建成功后，后续更改会直接写入该副本。请保留原始备份：直接保存过程中若程序异常终止，副本可能不完整，需要从原始备份重新创建。

PlanBak 支持使用 `Manifest.db` 的备份，不支持旧版 `Manifest.mbdb`。部分特殊文件无法作为普通文件导出。编辑后的备份能否恢复取决于设备及备份内容；项目曾对一个加密备份副本完成真机恢复验证，但不能保证所有场景均可恢复。

备份内容在本机处理。查看和编辑时，解密内容可能暂存于系统临时目录；正常关闭时会清理，异常退出后会在后续启动时清理符合条件的旧会话缓存。
